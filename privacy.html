プライバシーポリシー

最終更新：2026年9月8日

「training support」（以下「本アプリ」）は、利用者のプライバシーを尊重します。本ポリシーは、本アプリが扱う情報とその取り扱いを説明します。

1. 保存する情報

トレーニングの記録（種目・重量・回数・日付）、体重、メニュー、アプリの設定は、原則としてお使いの端末の中にのみ保存されます。運営者がこれらを閲覧することはありません。

2. サーバーに送る情報

  • AI相談：相談文と、直近14日分の記録の要約（種目・重量・回数・体重・継続日数）を、回答を作るために運営者のサーバーを通じて Anthropic 社の API に送ります。氏名・メールアドレスなどの個人を特定する情報は送りません。送信した内容は回答生成のためにのみ使われます。
  • 端末の識別子：プランと利用回数を管理するため、端末が生成したランダムな文字列を送ります。この文字列から個人を特定することはできません。
  • アカウント同期（任意）：Google または Apple でサインインした場合、記録はアカウントに紐づけて保存され、機種変更時の引き継ぎに使われます。

3. 決済情報

Web 版のお支払いは Stripe, Inc. が処理します。iOS アプリのお支払いは Apple の App 内課金（RevenueCat 経由で管理）を通じて行われます。クレジットカード番号などの決済情報を本アプリや運営者が保持することはありません。

4. 利用目的

取得した情報は、本アプリの機能提供、プランの管理、不正利用の防止、サービスの改善のためにのみ利用します。第三者に販売・提供することはありません（法令に基づく場合を除く）。

5. 情報の削除

端末内の記録はアプリの「その他の設定」からいつでも書き出し・削除できます。サーバー上の情報の削除をご希望の場合は、下記の連絡先までお知らせください。

6. 変更

本ポリシーは必要に応じて改定します。重要な変更がある場合は、アプリ内でお知らせします。

7. 連絡先
