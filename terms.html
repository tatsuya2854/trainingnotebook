利用規約

最終更新：2026年9月8日

この利用規約（以下「本規約」）は、「training support」（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用することで、本規約に同意したものとみなします。

1. サービス内容

本アプリは、トレーニングの記録・体重の管理・メニューの提案・AIによる相談機能を提供します。記録機能は無料で利用できます。AI相談の回数や複数クライアントの管理など一部の機能は有料プランの対象です。

2. 有料プランと自動更新

  • 有料プラン（プロ・マックス・トレーナー）は月額のサブスクリプションです。料金はアプリ内の表示に従います。
  • サブスクリプションは、期間終了の24時間前までに解約されない限り、同じ期間・同じ料金で自動更新されます。
  • iOS アプリでの購入は Apple ID に請求され、解約・変更は iOS の「設定 → Apple ID → サブスクリプション」から行えます。
  • Web 版での購入はクレジットカード（Stripe）で請求され、解約・変更はアプリ内の「お支払いを管理」から行えます。
  • 解約後も、支払い済みの期間の終了までは有料機能を利用できます。日割りの返金は行いません（法令で定められた場合を除く）。

3. AI相談について

AI相談の回答は AI が生成した一般的な情報であり、医療・栄養・法律などの専門的な助言ではありません。痛みや体調不良がある場合は、医師など専門家に相談してください。回答に基づく行動はご自身の判断と責任で行ってください。

4. 禁止事項

本アプリの不正利用、他者の権利侵害、サーバーへの過度な負荷、リバースエンジニアリングなどを禁止します。違反があった場合、利用を停止することがあります。

5. 免責

本アプリは現状有姿で提供されます。記録の消失、サービスの中断、AIの回答内容などによって生じた損害について、運営者は故意または重過失がある場合を除き責任を負いません。端末内の記録は定期的にバックアップしてください。

6. 規約の変更

本規約は必要に応じて変更することがあります。変更後の規約はアプリ内または本ページに掲載した時点で効力を持ちます。
